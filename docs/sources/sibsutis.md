## Важные оговорки

1. **Минимальный балл ≠ проходной.** Первый — порог для участия в конкурсе,
   второй — фактический cutoff зачисления.
2. **Группа 11.03.00.** Направления 11.03.01, 11.03.03 и 11.03.04 образуют
   многопрофильный конкурс: 112 бюджетных и 8 платных мест на группу,
   проходной балл 171. В базе есть отдельная запись группы, чтобы не дублировать
   места на каждом направлении.
3. **Заочный бакалавриат** — без бюджетных мест. Для 09.03.03, 20.03.01 и
   42.03.01 указана заочная форма с применением ДОТ.
4. **Магистратура 10.04.01 и 42.04.01** не имеет государственной аккредитации;
   бюджетных мест нет.
5. **Стоимость** указана за год обучения, не за семестр: очный бакалавриат и
   специалитет — 200 000 ₽/год, заочный бакалавриат — 80 000 ₽/год,
   магистратура — 190 000–215 000 ₽/год (очно) и 85 000 ₽/год (заочно).
6. **Сроки**: бюджет — до 25.07.2026 (бакалавриат/специалитет) и до 10.08.2026
   (магистратура); платно — до 20.08.2026 и 10.08.2026 соответственно.
7. **Не заполнено**: институты/факультеты, индивидуальные достижения, квоты,
   количество мест по квотам. Это следующие шаги.

## Как пересобрать

```powershell
python scripts/seed_sibguti.py
python scripts/check_data.py
python -m src.rag.build_chunks
python -m src.eval.run_eval
```

`seed_sibguti.py` — единственный источник правды для этих 30 записей. Если
правите JSON вручную, не запускайте скрипт повторно, иначе он перезапишет файлы.
