# Чек-лист источников по вузам

Заполняйте по мере сбора. Цель — не «скачать сайт», а получить по каждому вузу
полный набор: программы, предметы, минимальные и проходные баллы, сроки, стоимость,
и **ссылку-источник** на каждую цифру.

Повторить проверку: `python scripts/check_sites.py --timeout 10`.

## Где искать данные на сайте вуза

Типовой путь:

1. «Приёмная комиссия» / «Абитуриенту».
2. «Направления подготовки» / «Перечень специальностей».
3. «Проходные баллы» (часто PDF/Excel за прошлый год).
4. «Стоимость обучения».
5. «Сроки приёма документов».
6. «Минимальные баллы» (отдельно от проходных!).

## Definition of done по вузу

- [ ] все уровни (бакалавриат/специалитет/магистратура) и формы обучения;
- [ ] коды и названия направлений;
- [ ] бюджетные и платные места;
- [ ] предметы: обязательные + по выбору + ДВИ;
- [ ] минимальные баллы по предметам;
- [ ] проходные баллы на бюджет/платно с указанием года;
- [ ] сроки подачи документов;
- [ ] стоимость обучения (для платных мест);
- [ ] у каждой записи заполнен `sources[]` с URL и датой.

## Если сайт отдаёт 403

Так бывает: часть вузов блокирует зарубежные IP или незнакомые User-Agent.
Варианты по убыванию корректности:

1. Запустить сбор из сети вуза/с российского IP (на хакатоне вы и так там).
2. Сохранить страницу вручную из браузера и положить в `data/raw/` вместе с `.meta`
   (URL + дата). Парсер подхватит её так же, как скачанную.
3. Использовать официальные открытые данные (если вуз их публикует).
4. Спросить ментора/организаторов про разрешённые источники.

Не обходите защиту и не подделывайте User-Agent под браузер: это риск для проекта
и для репутации на защите.
